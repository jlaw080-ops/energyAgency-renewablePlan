# 신재생에너지센터 자동입력·크롤링 (크롬 확장 프로그램)

[한국에너지공단 신재생에너지센터 로그인 화면](https://nr.energy.or.kr/C0/CST_C0/login.do)에서

1. **기관(사업자)을 검색**하면 구글 시트에 정리된 **사업자등록번호**를 찾아 자동으로 입력하고,
2. **미리 등록해 둔 사용자**를 고르면 그 사용자의 **휴대폰 번호**를 자동으로 입력해 주는

크롬(또는 엣지) 확장 프로그램입니다.
로그인 후에는 신청서 목록의 **설치계획서 정보를 구글 시트로 모으는 크롤링** 기능도 있습니다(7장). 모은 설치계획서를 **나라 앱(사업 조회 서버)으로 보낼** 수도 있습니다(7장 끝). 코드는 `extension/` 폴더에 있습니다.

> 왜 확장 프로그램인가요?
> 다른 회사의 웹사이트(nr.energy.or.kr) 화면에 값을 대신 채워 넣으려면, 브라우저 안에서 그 페이지에 직접 손을 댈 수 있어야 합니다.
> 이것은 Vercel 같은 별도 웹사이트로는 불가능하고, 브라우저 확장 프로그램만 할 수 있습니다.
> 별도 서버가 필요 없고, 모든 데이터(사용자 이름·휴대폰 번호)는 내 크롬 안에만 저장됩니다.

---

## 1. 설치 방법 (개발자 모드로 불러오기)

크롬 웹스토어에 올리지 않고 내 PC에서 바로 쓰는 방법입니다. 5분이면 됩니다.

1. 이 저장소를 내려받습니다.
   - GitHub 페이지에서 초록색 **Code ▸ Download ZIP** 을 누르고 압축을 풉니다. (또는 VS Code에서 clone)
   - 압축을 푼 폴더 안에 `extension` 폴더가 있는지 확인합니다.
2. 크롬 주소창에 `chrome://extensions` 를 입력해 엽니다. (엣지는 `edge://extensions`)
3. 오른쪽 위 **개발자 모드** 스위치를 켭니다.
4. 왼쪽 위 **압축해제된 확장 프로그램을 로드합니다** 버튼을 누르고, **`extension` 폴더**를 선택합니다.
   (저장소 전체 폴더가 아니라 그 안의 `extension` 폴더입니다. `manifest.json` 파일이 들어 있는 폴더)
5. 목록에 "신재생에너지센터 로그인 자동입력"이 나타나면 설치 완료입니다.

> 폴더를 옮기거나 지우면 확장 프로그램이 꺼집니다. 폴더는 그대로 두세요.

## 2. 사용자(휴대폰 번호) 등록

1. 크롬 오른쪽 위 퍼즐 조각(확장 프로그램) 아이콘 ▸ **신재생에너지센터 로그인 자동입력** 을 클릭하면 설정 페이지가 열립니다.
   (또는 `chrome://extensions` ▸ 해당 확장 프로그램의 **세부정보** ▸ **확장 프로그램 옵션**)
2. **1. 사용자(휴대폰 번호) 등록** 칸에 이름과 휴대폰 번호를 넣고 **추가**를 누릅니다.
   여러 명을 등록할 수 있고, ▲▼ 로 순서를 바꾸거나 삭제할 수 있습니다.

## 3. 로그인 화면에서 사용하기

1. https://nr.energy.or.kr/C0/CST_C0/login.do 에 접속하면 화면 오른쪽 아래에 초록색 **"로그인 자동입력"** 패널이 나타납니다.
2. **기관(사업자) 검색** 칸에 기관명 일부(예: `강원대`)나 사업자번호 일부를 입력하고, 목록에서 기관을 클릭(또는 ↑↓ 키로 고르고 Enter)합니다.
   → 선택 즉시 페이지의 **사업자등록번호 칸이 채워집니다.**
3. **사용자 선택**에서 사용자를 고릅니다.
   → 고르는 즉시 **휴대폰 번호 칸이 채워집니다.** (마지막에 고른 사용자는 다음에도 기억됩니다)
4. 이후 인증번호 받기 / 로그인은 평소처럼 진행하면 됩니다.

패널은 제목 부분을 끌어서 옮길 수 있고, `－` 버튼으로 접을 수 있습니다.

### 입력칸을 못 찾는다고 나올 때

패널이 "입력칸을 찾지 못했습니다"라고 하면, 사이트의 입력칸 이름이 예상과 달라서 그렇습니다. 한 번만 알려 주면 됩니다.

1. 패널 아래 **사업자칸 지정** (또는 **휴대폰칸 지정**) 을 누릅니다.
2. 페이지에서 실제 **사업자등록번호 입력칸을 클릭**합니다. (마우스가 십자 모양이 됩니다)
3. "입력칸을 저장했습니다"가 뜨면 끝입니다. 이후에는 자동으로 그 칸에 들어갑니다.

입력칸이 `000` `-` `00` `-` `00000` 처럼 3칸으로 나뉘어 있어도 자동으로 나누어 넣습니다.
하이픈 포함/미포함은 입력칸의 최대 글자수를 보고 자동 판단하며, 설정 페이지 **3. 입력칸 지정**에서 강제로 바꿀 수 있습니다.

## 4. 기관(사업자등록번호) 데이터 갱신

확장 프로그램에는 [구글 시트](https://docs.google.com/spreadsheets/d/1aIUyHK8FrLSot9zL4Z-j9W0C6KQNDL5dz45tdC40elc/edit?usp=sharing)의
기관명·사업자번호(중복 제거 후 1,778곳)가 `extension/data/orgs.json` 파일로 미리 담겨 있습니다.

시트를 수정한 뒤 최신 내용으로 바꾸려면:

1. 설정 페이지 ▸ **2. 기관(사업자등록번호) 데이터** ▸ **시트에서 최신 데이터 가져오기** 를 누릅니다.
2. 시트는 **"링크가 있는 모든 사용자 – 뷰어"** 로 공유되어 있어야 합니다.
3. 시트의 첫 번째 탭을 읽습니다. 다른 탭을 읽으려면 시트 주소 끝의 `gid=숫자` 값을 **시트 탭 gid** 칸에 넣으세요.
4. 열 제목에 `기관명`, `사업자번호` 가 있으면 그 열을 사용하고, 없으면 2번째·3번째 열을 사용합니다.

**내장 데이터로 되돌리기**를 누르면 원래 담겨 있던 데이터로 돌아갑니다.

## 5. 폴더 구성

```
extension/
├── manifest.json      확장 프로그램 정보 (권한, 적용 사이트 등)
├── background.js      탭 안의 여러 프레임(iframe)에 채우기 명령을 전달
├── fill.js            입력칸을 찾아 값을 넣는 핵심 로직 (키워드 탐지, 3칸 분할, 형식 판단)
├── content.js         로그인 페이지 위에 뜨는 패널 UI (검색·사용자 선택)
├── content.css        패널 스타일
├── crawl.js           설치계획서 크롤링 (목록 순회, 팝업 읽기, 시트 기록)
├── options.html/.js   설정 페이지 (사용자 등록, 시트 동기화, 입력칸 지정, 크롤링 시트 연결)
├── apps-script/Code.gs  구글 시트에 붙여넣는 기록용 스크립트 (설정 페이지에서 복사)
└── data/orgs.json     구글 시트에서 뽑은 기관명·사업자번호 (내장본)
```

## 6. 개인정보 / 보안

- 사용자 이름과 휴대폰 번호는 크롬의 확장 프로그램 저장소(`chrome.storage.sync`)에만 저장됩니다. 같은 구글 계정으로 로그인한 내 다른 크롬에도 동기화되며, 외부 서버로 보내지 않습니다.
- 확장 프로그램은 `nr.energy.or.kr` 페이지와 (데이터 갱신 시에만) `docs.google.com` 에만 접근합니다. 나라 앱으로 보내기를 켜면 설정에 적은 그 주소에도 접근합니다(저장할 때 크롬이 허용 여부를 묻습니다).
- 나라 앱 토큰은 이 PC의 확장 프로그램 저장소(`chrome.storage.local`)에만 두고 동기화하지 않습니다.
- 비밀번호나 인증번호는 다루지 않습니다.

## 7. 설치계획서 크롤링 → 구글 시트

로그인 후 신청서 목록에서 건물명을 하나씩 열어 설치계획서 내용을 구글 시트 **설치계획** 탭에 한 행씩 추가합니다.

| 시트 열 | 내용 |
|---|---|
| A | 기관명 |
| B | 건물명 |
| C | 건물주소 (우편번호 제외) |
| H | 착공예정일 (YYYY-MM-DD) |
| I | 준공예정일 (YYYY-MM-DD) |
| J | 담당부서 (의무기관 담당자 부서) |
| R | 신재생에너지원 개요. 예: `지열 수직밀폐형: 336.060 kW` (여러 개면 줄바꿈) |

- **준공예정일이 실행일보다 이전이면 시트에 쓰지 않고 제외**합니다.
- **착공예정일이나 준공예정일이 비어 있으면 제외**합니다. 이런 건은 날짜가 나중에 입력될 수 있어 다음 크롤링 때 다시 확인합니다.
- 처리한 건은 작업 기록에 남아 다음 실행 때 다시 열지 않습니다 (신청번호 기준, 작성중 건은 기관명+건물명 기준).
- 시트에 같은 기관명+건물명 행이 이미 있으면 새로 쓰지 않습니다.
- 한 페이지를 마치면 다음 페이지 번호를 눌러 끝까지 진행합니다.

### 처음 한 번: 시트 연결 (5분)

확장 프로그램은 구글 시트에 직접 쓸 수 없어서, 시트에 작은 스크립트(Apps Script 웹 앱)를 붙여 다리로 씁니다.

1. 설정 페이지 4번 ▸ **처음 한 번: 시트 연결 방법** 을 펼치고 **코드 복사** 를 누릅니다.
2. 기록할 구글 시트를 열고 메뉴 **확장 프로그램 ▸ Apps Script** 를 누릅니다.
3. 편집기 내용을 모두 지우고 붙여넣은 뒤 저장합니다.
4. **배포 ▸ 새 배포 ▸ 웹 앱** 을 고르고, 실행은 **나**, 액세스 권한은 **모든 사용자** 로 두고 배포합니다. 권한 승인 창이 뜨면 허용합니다.
5. 나오는 **웹 앱 URL** 을 설정 페이지에 붙여넣고 **저장 후 연결 테스트** 를 누릅니다. "연결 성공"이 뜨면 끝입니다.

> 코드 안의 토큰은 이 PC 전용 비밀값입니다. 웹 앱 URL과 함께 다른 사람에게 공유하지 마세요.

### 실행

1. 크롬에서 **nr.energy.or.kr 팝업 차단을 해제**합니다 (주소창 오른쪽 아이콘 ▸ 항상 허용). 크롤링은 팝업을 열어 읽기 때문에 필수입니다.
2. 로그인 후 신청서 목록 화면으로 갑니다. 오른쪽 아래 파란 **설치계획 크롤링** 패널이 나타납니다 (로그인 패널이 있으면 그 왼쪽).
3. **크롤링 시작** 을 누르면 팝업이 차례로 열렸다 닫히며 진행됩니다. 중간에 **중지** 할 수 있고, 다시 시작하면 남은 건부터 이어집니다.
4. 결과와 기록은 설정 페이지 4번 **작업 기록** 에서 확인합니다. 시트 연결 없이 돌렸다면 **수집 결과 복사** 로 시트에 붙여넣을 수 있습니다.

### 팝업이 자동으로 열리지 않을 때 (직접 클릭 모드)

크롬은 사람이 누르지 않은 클릭으로 팝업을 여는 것을 막을 때가 있습니다. 이때 크롤러는 8초 안에 팝업이 안 열리면 **직접 클릭 모드**로 바뀝니다.

- 다음에 처리할 건물명이 **노란색**으로 깜빡입니다. 그 건물명을 직접 누르면 팝업을 읽고 닫은 뒤 다음 건물을 표시합니다.
- 페이지 이동, 준공일 판단, 시트 기록은 그대로 자동입니다.

### 문제가 생겼을 때

패널 오른쪽 아래 **진단 정보 복사** 를 누르면 목록 표·페이지 번호·팝업 화면 구조가 복사됩니다. 채팅에 붙여넣어 보내 주시면 원인을 바로 찾을 수 있습니다. 개인정보(휴대폰 번호 등)는 포함되지 않습니다.

### 나라 앱으로 보내기 (선택)

크롤링한 설치계획서를 나라 앱(사업 조회 서버)에도 보냅니다. 나라 앱은 받은 설치계획서를 사업과 짝지어 신재생 계획·착공/준공일·주소·실행부서를 채우고, 짝이 없으면 새 사업으로 추가합니다.

1. 나라 앱 `.env`에 `NARA_IMPORT_TOKEN`이 있고 서버가 떠 있어야 합니다.
2. 설정 페이지 **5. 나라 앱으로 보내기**에 나라 앱 주소(예: `http://127.0.0.1:8000`)와 같은 토큰을 넣고 **저장 후 연결 테스트**를 누릅니다. 크롬이 그 주소에 접근해도 되는지 물으면 허용합니다.
3. "연결 성공"이 뜨면 이후 크롤링부터 한 건마다 나라 앱으로도 보냅니다. 시트 연결과 함께 써도 되고, 나라 앱만 써도 됩니다.

- 보내는 건은 시트와 같습니다(착공·준공예정일이 있고 준공예정일이 지나지 않은 건). 시트에 이미 있는 건도 나라 앱으로는 보냅니다.
- 보내기가 실패하면 크롤링을 멈추고, 그 건은 기록하지 않아 다음 실행 때 다시 보냅니다.
- 나라 앱 결과(연결·새 사업·확인 필요)는 작업 기록에 남고, 나라 앱의 **설치계획** 화면에서 확인할 수 있습니다.
