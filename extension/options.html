자동입력·크롤링 설정

nr.energy.or.kr 로그인 화면에서 쓸 사용자(휴대폰 번호)와 기관 데이터를 관리합니다.

1. 사용자(휴대폰 번호) 등록

등록해 두면 로그인 화면 패널에서 사용자를 고르는 것만으로 휴대폰 번호가 채워집니다.

#이름휴대폰

2. 기관(사업자등록번호) 데이터

확장 프로그램에는 구글 시트 내용이 미리 담겨 있습니다. 시트를 수정했다면 아래 버튼으로 최신 내용을 다시 불러오세요. (시트는 "링크가 있는 모든 사용자 보기" 공유 상태여야 합니다.)

3. 입력칸 지정 (자동으로 못 찾을 때만)

보통은 비워 두면 됩니다. 로그인 화면 패널의 "사업자칸 지정 / 휴대폰칸 지정"을 눌러 입력칸을 클릭하면 여기에 자동으로 저장됩니다. 직접 CSS 셀렉터를 적어도 됩니다 (여러 칸이면 쉼표로 구분).

4. 설치계획 크롤링 → 구글 시트

로그인 후 신청서 목록 화면 왼쪽 아래 설치계획 크롤링 패널에서 시작합니다. 건물명을 하나씩 열어 착공·준공예정일이 모두 있고 준공예정일이 지나지 않은 건만 시트에 한 행씩 추가합니다.
기록 열: A 기관명 · B 건물명 · C 건물주소 · H 착공예정일 · I 준공예정일 · J 담당부서 · R 신재생에너지원 개요

처음 한 번: 시트 연결 방법 (5분)
  1. 기록할 구글 시트를 엽니다. 메뉴 확장 프로그램 → Apps Script를 누릅니다.
  2. 편집기 내용을 모두 지우고, 아래 코드 복사 버튼으로 복사한 코드를 붙여넣은 뒤 저장(💾)합니다.
  3. 오른쪽 위 배포 → 새 배포 → 톱니바퀴에서 웹 앱을 고릅니다.
    실행: 나 / 액세스 권한: 모든 사용자 로 두고 배포를 누릅니다.
  4. 권한 승인 창이 뜨면 본인 계정 → (고급) → 이동 → 허용을 누릅니다.
  5. 나오는 웹 앱 URL(https://script.google.com/macros/s/…/exec)을 아래 칸에 붙여넣고 저장 후 연결 테스트를 누릅니다.
코드 안에 이 PC 전용 비밀값(토큰)과 시트 탭 이름이 들어 있습니다.

작업 기록

기록에 있는 건(신청번호 기준)은 다음 크롤링 때 다시 열지 않습니다. 준공예정일이 지나 제외한 건도 기록됩니다. 착공·준공예정일이 비어 제외한 건은 날짜가 나중에 입력될 수 있어 다음 크롤링 때 다시 확인합니다.

5. 나라 앱으로 보내기

크롤링한 설치계획서를 나라 앱(사업 조회 서버)에도 보냅니다. 시트 연결과 함께 써도 되고, 나라 앱만 써도 됩니다.
나라 앱 .env의 NARA_IMPORT_TOKEN 값을 토큰 칸에 그대로 넣습니다. 저장할 때 그 주소에 접근해도 되는지 크롬이 한 번 묻습니다.
